# Order Management System — Microservices Learning Project

A step-by-step, hands-on .NET 8 microservices project built to solidify
enterprise .NET patterns: Repository, Unit of Work, DI lifetimes, REST API
design, Saga pattern, JWT auth, API Gateway, Docker, Redis caching, and more.

This project is intentionally simple on the business-logic side — the goal is
to demonstrate architecture and patterns, not complex domain rules.

## Services
- **OrderService** — handles order creation and management
- **InventoryService** — (coming later) handles stock/inventory checks and
  reservations
